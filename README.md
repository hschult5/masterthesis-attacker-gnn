# Model-Guided Block Selection for PR-BCD Attacks on Graph Neural Networks

This repository contains the implementation and experiments for Studies 1–3 of this Master's thesis. It builds on the implementation of the PR-BCD attack by Geisler et al., a first-order structural evasion attack on graph neural networks.

**Study 1** investigates how the block size and the duration of the resampling phase influence 
PR-BCD's attack strength and optimization trajectory. 
It further examines whether, when, and to what extent PR-BCD could benefit 
from proposed perturbations that are not discovered by its randomized block sampling/resampling scheme.

**Study 2** builds on the findings of Study 1 by introducing two notions of proposed perturbation harmfulness that are 
distinct from the PR-BCD notion of harmfulness. These harmfulness objectives are evaluated both as direct structural perturbations 
and with respect to their usefulness within the PR-BCD optimization process.

**Study 3** uses the harmfulness objectives defined in Study 2 to construct labels for proposed perturbations and train a simple selector GNN.
The selector learns to identify structural perturbations that are consistent with these harmfulness objectives.
Its predictions are then used to guide PR-BCD's block sampling and resampling.

We call this modified PR-BCD attack **Projected Selector-Guided Block Coordinate Descent (PSG-BCD)**.

## Code Base

This repository builds on the PR-BCD implementation provided by Geisler et al.
The original code base, PR-BCD infrastructure, and dependency setup are the
foundation of this repository.

Additional code that belongs directly to the results in the thesis we implemented and includes:

- Jupyter notebooks RQ1.ipynb and RQ2_RQ3.ipynb that directly execute experiments done in Study 1 and Study 2-3 respectively.
- Helper file selector_pipeline_helpers.py that support the implementation of the notebooks
- Helper file old_mining_cache_helper.py, that loads the scored candidate sets used throughout this thesis.
- Jupyter notebook loss_plotting.ipynb that plots the validation and training loss of the selector.
- Patches to the original implementation of PR-BCD. Namely to experiment_global_attack_direct.py, common.py, base_attack.py and prbcd.py to facilitate logging needed for our experiments and execute PSG-BCD.

For details on the original PR-BCD implementation, please refer to:
https://github.com/sigeisler/robustness_of_gnns_at_scale

The environment contains all Python packages used for the experiments and analysis.

Create the environment with:


Activate it using:


PyTorch, PyTorch Geometric, Sacred, SEML, scientific Python, and Jupyter
dependencies used throughout the project.

## Windows / SEML Compatibility

The experiments were executed on Windows. With a patch for the SEML library. To get this running on windows implement a patch by replacing the SEML file experiment.py by the provided config/experiment.py

## Running the Experiments

The experiments for all three studies can be reproduced directly from the provided Jupyter notebooks:

- `notebooks/RQ1.ipynb` contains the experiments for **Study 1**.
- `notebooks/RQ2_RQ3.ipynb` contains the experiments for **Studies 2 and 3**.

The notebooks already contain the hyperparameter configurations used for the experiments reported in the thesis. Therefore, no additional hyperparameter configuration should be required to reproduce the reported runs.
